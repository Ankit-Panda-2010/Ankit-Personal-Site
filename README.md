# Ankit — Personal Portfolio

A modern React and Tailwind CSS portfolio skeleton, ready to be personalized with real experience, projects, links, and a portrait.

## Run locally

```bash
npm install
npm run dev
```

## Personalize

The editable content lives near the top of `src/App.jsx`:

- `projects` — featured project cards
- `experience` — career timeline
- `capabilities` — skills and focus areas
- About copy, contact email, LinkedIn, and GitHub links in the component markup

Replace `hello@example.com` before sharing publicly.
